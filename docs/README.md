# Декомпозиция FakeNFT

Диплом делаю один. Доска с задачами, оценкой и реальным временем: https://github.com/users/StarNinja38/projects/1

По согласованию с куратором беру один эпик: «Каталог». Задачи:

- [Общая основа](common.md): дизайн, таб-бар, модели, сервисы, общие вью
- [Каталог](catalog.md): список коллекций, экран коллекции, лайки и корзина, веб-вью автора

## Решения

- Архитектура: MVVM, связь View и ViewModel через замыкания
- Вёрстка: UIKit, всё в коде, без сторибордов
- Сеть: URLSession через DefaultNetworkClient, ответы на главной очереди, тяжёлая работа на global(qos: .userInitiated), параллельные запросы через DispatchGroup
- Swift Concurrency не используется
- Минимальная версия iOS 17.0
- Картинки через Kingfisher, лоадер UIActivityIndicatorView
- Сортировки хранятся в UserDefaults
- Токен лежит в Secrets.xcconfig, его нет в репозитории

## Запуск

Токена нет в репозитории. Чтобы запустить, рядом с Config.xcconfig нужен файл Secrets.xcconfig со строкой PRACTICUM_TOKEN = <токен>.

## Ветки

main → develop → epic-fakenft → epic-fakenft-1, epic-fakenft-2, epic-fakenft-3

Каждая часть делается в своей ветке от epic-fakenft и вливается в неё через PR. После третьей части epic-fakenft вливается в develop.

Колонка «Факт» заполняется после каждой задачи.
